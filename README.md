# 바삭치킨 메인 컨셉 시안 3종

치킨 프랜차이즈 브랜드 사이트의 메인 페이지를 세 가지 방향으로 만든 시안입니다.

| 시안 | 폴더 | 방향 |
|---|---|---|
| A BOLD | `a-bold/` | 흰 바탕의 에디토리얼 구성, 영상 KV, 스크롤 와이프 메뉴, 프레임 시퀀스 필름 챕터 |
| B POP | `b-pop/` | 코발트 블루와 옐로의 평면 듀오톤, 3D 닭다리, 분해 레이어, 확장 핀 연출 |
| C WARM | `c-warm/` | 크림과 브라운의 따뜻한 톤, 컬러 블록 메뉴 캐러셀, 마스코트 |

## 구성
- 순수 HTML, CSS, 바닐라 JS. 빌드 과정이 없습니다.
- 라이브러리(GSAP, ScrollTrigger, Lenis, Swiper, three.js)는 `vendor/`에 포함되어 있습니다.
- 이미지, 영상, 3D 모델은 AI로 생성했습니다. 인물은 모두 가상 인물입니다.
- 브랜드명 "바삭치킨"은 시안용 가칭입니다.

## 로컬에서 보기
```bash
npx http-server . -p 4173 -c-1
```
브라우저에서 `http://localhost:4173` 을 엽니다. 영상과 3D 모델 때문에 파일을 직접 여는 방식이 아니라 로컬 서버가 필요합니다.
